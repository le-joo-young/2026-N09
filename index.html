CHAPTER 01

생성형 AI 이해 및 업무별 모델 활용

AI 도구 로그인·보안 설정을 마친 뒤 RCTF 프레임워크를 익히고,
본인 업무에 직접 적용한 뒤 팀별 예제 실습으로 심화합니다.

생성형 AI(ChatGPT, Claude, Gemini 등)는 다음과 같이 동작합니다.

  1. 입력: 사용자가 "○○의 크기는?"이라고 질문
  2. 패턴 검색: 학습 데이터에서 유사한 패턴 찾기
  3. 확률 계산: 다음 단어의 출현 확률 계산 (예: 숫자A: 0.7, 숫자B: 0.3…)
  4. 단어 생성: 확률이 높은 순서대로 단어 출력
  5. 자신감 표현: 검증 과정 없이 그대로 전달
핵심 · 할루시네이션(환각 현상) 주의

AI는 "정확한 답"과 "그럴듯한 답"을 구분하지 못하므로, 학습 데이터에 없는 내용도 진실처럼 지어낼 수 있습니다. 이 실습에서 계속 "검증 기준"과 "금지"를 프롬프트에 넣는 이유가 여기에 있습니다.

주요 도구별 특징 — (주)엔공구 업무 관점

ChatGPT이미지 생성이 강하고, GPTs로 반복 업무를 저장해 재사용할 수 있음 → 상세페이지 이미지 초안, 커스텀 CS 응대봇에 적합
Claude긴 문서·대용량 표 처리에 강하고, 결과물을 코드 실행으로 바로 확인 가능 → 판매데이터 분석, 보고서 초안 작성에 적합
GeminiGmail·Docs·Sheets 등 구글 워크스페이스와 연동되고, Gem으로 반복 업무를 저장할 수 있음 → 이메일 자동 발송, 반복 업무 자동화에 적합
RCTF 프레임워크
RoleAI에게 부여할 전문가 페르소나. "너는 10년 경력의 데이터 분석가야"처럼 실제 전문가 역할을 지정합니다.
담당자 본인이 아닌, 전문 지식을 가진 역할을 줄수록 답변 품질이 높아집니다.
Context판단에 필요한 배경 정보. 데이터, 상황, 제약 조건을 함께 제공합니다.
Task구체적으로 해야 할 작업. 결과물을 명확히 지정합니다.
Format결과를 받고 싶은 형태. 표, 목록, 요약 등으로 지정합니다.

CHAPTER 02

AI Agent와 자동화

Gemini Gems와 ChatGPT Projects를 직접 만들어보고, 본인 업무에 맞는 나만의 AI 비서를 완성합니다.

직무별 자동화 아이디어 매칭기 — 본인 직무를 선택해보세요

내 직무에서 자동화하기 좋은 반복 업무와 추천 Gem 시스템 프롬프트를 확인해보세요. 아래 실습 1~6번과는 별개로, Gem을 만들기 전 방향을 잡는 용도로 활용하세요.

Gemini Gems → ChatGPT Projects → 본인 업무 직접 만들기 순서로 진행됩니다.
  • 위 직무별 매칭기에서 방향을 먼저 잡은 뒤 실습을 시작하세요.
  • Gemini와 ChatGPT 중 본인이 더 자주 쓰는 것 하나를 골라 집중해도 됩니다.
  • 마지막 실습에서 본인 업무 시스템 프롬프트를 직접 작성하고 저장하는 것까지 완성하는 것이 목표입니다.

GAS 자동화

Google Apps Script 자동화 실습

Gem에 매번 데이터를 붙여넣어 결과를 받아오던 작업을, 구글시트 버튼 하나로 AI가 자동 분석·입력하는 구조로 만들어보는 실습입니다. 코드를 몰라도 템플릿을 그대로 따라 하면 완성됩니다.

  • 위 RCTF 프롬프트를 AI에 입력하면 Code.gs 코드가 생성됩니다.
  • CODE.GS 블록을 복사해서 Apps Script에 붙여넣기만 하면 동작합니다. 코드를 이해하지 않아도 됩니다.
