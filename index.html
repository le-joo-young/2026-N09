CHAPTER 01100분

생성형 AI 이해 및 업무별 모델 활용

프롬프트 설계 기본 틀인 RCTF를 익히고, (주)엔공구 판매 데이터를 직접 분석하며 업무에 AI를 적용하는 방법을 실습합니다.

각 실습은 데이터 → 프롬프트 → 후속 질문 3단계로 구성되어 있습니다.
  • data 블록을 복사해 ChatGPT / Claude / Gemini 중 사용 중인 AI 채팅창에 붙여넣습니다.
  • 이어서 prompt 블록을 그대로 붙여넣어 실행합니다.
  • 결과를 확인한 뒤 chain task의 후속 질문을 이어서 입력해 실습을 심화합니다.
정답을 찾는 게 목적이 아니라, 조건(RCTF)을 바꿨을 때 결과가 어떻게 달라지는지 직접 확인하는 것이 이번 교시의 목표입니다.
RCTF 프레임워크
RoleAI에게 맡길 역할. "너는 ○○팀 담당자야"처럼 관점을 지정합니다.
Context판단에 필요한 배경 정보. 데이터, 상황, 제약 조건을 함께 제공합니다.
Task구체적으로 해야 할 작업. 결과물을 명확히 지정합니다.
Format결과를 받고 싶은 형태. 표, 목록, 요약 등으로 지정합니다.
CHAPTER 02100분

실무 적용 실습

(주)엔공구 고객 Q&A · VOC 데이터를 활용해 자동응답을 설계하고, 본인 업무에 AI를 적용할 영역을 정리합니다.

1교시가 "데이터를 분석하는 실습"이었다면, 2교시는 "고객에게 직접 노출되는 응답을 만드는 실습"입니다.
  • 같은 data → prompt → chain task 구조를 따르되, 마지막 항목은 사수 검토 관점의 셀프체크로 마무리합니다.
  • AI가 만든 응답을 그대로 쓰지 않고, 왜 위험할 수 있는지 스스로 판단하는 연습이 포함되어 있습니다.
  • 5번(Gemini Gem)은 시간이 남으면 진행하는 심화 실습입니다. 1~4번을 먼저 마치고 여유가 있을 때 도전하세요.

본인 업무 적용

1교시의 RCTF와 2교시의 검수 기준을 본인 업무에 옮겨봅니다. 자동화할 영역과 사람이 남아야 할 영역을 나누는 것이 핵심입니다.

AI에 맡길 영역사람이 봐야 할 영역
반복 문의 1차 분류, 데이터 집계·요약, 초안 답변 작성최종 답변 검수, 과장·오정보 표현 확인, 예외 상황 판단
표기 오류 없는 데이터의 패턴 분석표기 불일치 등 데이터 품질 점검
